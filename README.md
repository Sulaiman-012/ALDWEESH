# منصة صندوق عائلة الدويش

تطبيق Next.js حقيقي (وليس Claude Artifact) مربوط بقاعدة بيانات Postgres على
Supabase، يسمح لأي عضو من الـ52 فردًا بالدخول برابط عام باسمه ورمز PIN من
4 أرقام، دون الحاجة لحساب Claude.

## خطوات التشغيل (مرة واحدة)

### 1) إنشاء مشروع Supabase (مجاني)
1. أنشئ حسابًا على https://supabase.com وأنشئ مشروعًا جديدًا.
2. من **SQL Editor** نفّذ محتوى الملف `supabase/schema.sql` كاملاً.
3. ثم نفّذ محتوى الملف `supabase/seed.sql` لتعبئة اللجان والحسابات (54 حسابًا،
   بما فيها الإدارة التنفيذية).
4. من **Project Settings → API** انسخ:
   - `Project URL` → سيصبح `SUPABASE_URL`
   - `service_role` secret key → سيصبح `SUPABASE_SERVICE_ROLE_KEY`
     (⚠️ لا تضعه أبدًا في كود عام أو في متغيرات NEXT_PUBLIC_)

### 2) رموز الدخول (PIN) الفعلية
ملف `supabase/PINS_CONFIDENTIAL.txt` يحتوي رمز الدخول الحقيقي (4 أرقام) لكل
فرد بنص صريح — لأن قاعدة البيانات تُخزّن فقط نسخة مُجزَّأة (bcrypt) لا يمكن
استرجاعها. **احتفظ بهذا الملف في مكان آمن ووزّع الرموز على الأعضاء بنفسك**
(مثلاً عبر واتساب لكل فرد على حدة)، ثم يُفضَّل حذف الملف من أي مكان مشترك.

### 3) النشر على Vercel
1. أنشئ حسابًا على https://vercel.com واربطه بمستودع GitHub يحوي هذا المجلد
   (أو ارفع المجلد مباشرة عبر Vercel CLI: `npx vercel`).
2. أضف متغيرات البيئة الثلاثة من `.env.example` في إعدادات المشروع على Vercel
   (Project Settings → Environment Variables).
3. اضغط Deploy — ستحصل على رابط دائم مثل `https://your-app.vercel.app`
   يمكن لأي فرد فتحه بدون حساب Claude أو حتى بدون حساب Google/بريد.
4. لاحقًا يمكن ربط دومين خاص (مثل `fund.aldweesh.family`) من
   Project Settings → Domains (يتطلب شراء دومين، حوالي 40–60 ريال سنويًا).

### 4) التشغيل محليًا (اختياري، للمطوّر)
```bash
npm install
cp .env.example .env.local   # ثم عبّئ القيم الحقيقية
npm run dev
```

## الحالة الحالية

كل الميزات الأساسية مبنية وتعمل فعليًا على قاعدة بيانات Supabase حقيقية:

- تسجيل دخول بالاسم + رمز PIN (مُجزَّأ bcrypt، غير مخزَّن كنص صريح).
- صلاحيات حسب الدور: مشرف النظام، مجلس الأمناء، الإدارة التنفيذية، ورئيس/سكرتير/عضو لكل لجنة.
- لوحة رئيسية بمؤشرات الأداء (KPIs) ونسبة الإنجاز.
- اللجان: عرض، الأعضاء المفوَّضون، **تقييم الإدارة التنفيذية للجنة** (درجة من 10 + ملاحظات).
- المهام: عرض/إضافة/تحديث الحالة — وكل عضو يرى مهامه المسندة له حتى لو لم يكن ضمن اللجنة.
- محاضر الاجتماعات: إضافة محضر بتوصيات، و**تحويل أي توصية إلى مهمة مسندة لشخص** تنعكس مباشرة في صفحة مهامه.
- الأفكار التطويرية: أي عضو يقترح فكرة، والإدارة التنفيذية تراجعها وتغيّر حالتها وترد عليها.
- اللوائح: يضيفها مشرف النظام يدويًا ويراها الجميع.
- الحسابات: مشرف النظام يضيف/يعدّل الحسابات، يعيد تعيين رموز الدخول، ويدير تفويضات الأعضاء على اللجان.

لا يوجد عمل متبقٍ من طلبات الميزات الأصلية — الخطوة التالية هي النشر الفعلي
(انظر خطوات Supabase و Vercel أعلاه) ثم اختبار الاستخدام الحقيقي وتحسينات
الشكل والتفاصيل حسب الملاحظات.
